# Сохранённое приложение iPhone: обмен приостановлен

Статус на **3 ноября 2026 года**: рабочий сервер использует `DATABASE_ONLY = True`. `MobileBridge.configure` отклоняет включение обмена, `run` возвращается без файлового обмена, интерфейс сообщает `paused`. Установка приложения или нажатие старой кнопки не включает обработчик на Mac.

Текущий доступ с iPhone развивается через адаптивный веб-интерфейс и отдельный защищённый HTTPS-вход. В этой документационной работе внешний DNS и сервис не изменялись. [Архитектура](../docs/architecture.md), [внешняя настройка](../docs/operations.md#удалённый-доступ).

## Что сохранено

| Файл | Назначение |
| --- | --- |
| `Core.swift` | Codable-модели, локальная карточка, черновики и неизменяемая очередь действий |
| `DriveTransport.swift` | Actor согласованного чтения iCloud, публикации операций и кеширования оригиналов |
| `PhoneApp.swift` | SwiftUI-экраны заказов, задач, файлов, очереди и выбора папки |
| `CoreTests.swift`, `check.sh` | Проверки локальной устойчивости и типов, синтаксис iOS-экрана |
| `ProtocolProbe.swift`, `protocol_check.py` | Межъязыковая проверка прежнего протокола на временном архиве |
| `ZigzagPhone.xcodeproj` | Сохранённый проект iOS |
| `../mobile_sync.py` | Старый обработчик Mac с блокировкой обмена в текущем режиме |

Прежний протокол использует `.mobile-sync` в корне архива: идентичность, каталог, отдельные неизменяемые операции и подтверждения. UUID/digest и исходная версия связывают действие с конкретной задачей/файлом. Публикация в iCloud не равна подтверждённому применению на Mac. Сохранённую очередь и receipts нельзя удалять как временный кеш.

## Как читать реализацию

[Swift и транспорт подробно](../docs/language/swift-c.md), [старый код и условия возврата](../docs/legacy-code.md), [все объявления](../docs/reference/README.md). Прежняя инструкция установки и первоначального обмена сохранена [только как исторический снимок](../docs/history/mobile-readme-paused-20261102.md). Сведения о старой успешной сборке относятся к её дате и не обещают текущую установку на устройство.

Для возврата функции нужны отдельное решение о протоколе SQLite, адаптация Mac/телефона и проверка двух устройств с перезапуском, повторами и конфликтами. Здесь такая адаптация не выполнялась.

## Локальные проверки

```sh
sh mobile/check.sh
python3 mobile/protocol_check.py
```

Они проверяют сохранённый код на временных данных. Подпись, установка на физический iPhone и реальная доставка через iCloud ими не проверяются.
