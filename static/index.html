Обмен с iPhone

      
На iPhone можно просматривать заказы, добавлять комментарии к заказам и файлам, вести To-do без связи. Изменения передаются через iCloud, когда он доступен.

      
Подготовьте обмен здесь, затем в приложении iPhone выберите папку «Зигзаг» в iCloud Drive. Для первой установки приложения потребуется Xcode на Mac.

Убрать из списка заказов?

        

        
Папка, вложения и данные карточки сохранятся. Вложенные заказы останутся в списке. Добавить эту папку обратно можно вручную.

        

      

    
    
      
Переместить файлы в корзину?
    Файлы и их комментарии сохранятся в корзине менеджера. Их можно будет восстановить кнопкой «Корзина».
