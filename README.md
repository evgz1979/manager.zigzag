# Менеджер заказов «Зигзаг»

Локальный просмотр папок клиентов и заказов. Код находится в ~/Documents/manager, документы остаются в своей папке на диске.

## Настройка

Путь к документам задаётся в **[manager.ini](manager.ini)**, в секции [storage]:

    [storage]
    root = ~/Library/Mobile Documents/com~apple~CloudDocs/Зигзаг

    [server]
    host = 0.0.0.0
    port = 8765

root может быть абсолютным путём, путём с ~ или относительным путём от INI. После изменения настроек перезапустите сервер. Переменные ZIGZAG_DATA_ROOT и MANAGER_HOST, если заданы, переопределяют соответствующие настройки INI.

## Структура и интерфейс

- Папки клиентов лежат непосредственно в корне данных.
- Корневые папки с # показаны отдельными кнопками над деревом клиентов.
- Слева — раскрываемое дерево папок с фактической вложенностью на диске.
- Годы, объекты, заказы и этапы остаются обычными папками: обязательного уровня года и фиксированной глубины нет.
- Вложенные папки с # остаются внутри своего клиента или заказа.
- Справа — подпапки и все файлы выбранной папки, включая файлы из её подпапок. По умолчанию файлы сгруппированы по папкам; доступны поиск, фильтр по типу и сортировка.
- Фото (включая HEIC/TIFF), PDF, текст и поддерживаемые браузером видео и аудио можно смотреть внутри менеджера. Макеты и остальные форматы открываются в установленной программе на Mac.
- Статус и заметка сохраняются в файле «.status.txt» внутри выбранной папки. Его можно открыть и отредактировать без менеджера. При переходе к другой папке несохранённые изменения записываются автоматически.
- Скрытые файлы и символические ссылки не включаются в дерево и списки файлов.

Служебные файлы скрыты: чтобы показать их в Finder, нажмите ⌘⇧. (Command + Shift + точка). Вся рабочая информация хранится в каталогах документов; правила закреплены в AGENTS.md. В data/ остаются только восстанавливаемые технические файлы: кеш просмотров, сборка и журналы работы. Документы не перемещаются и не переименовываются.

При первом запуске прежние статусы из data/statuses.json переносятся в файлы соответствующих папок. Старый JSON сохраняется в корне документов как «.legacy-statuses.json»; несопоставленные записи остаются в этом архиве. Уже существующие файлы статуса не перезаписываются.

Формат файла статуса (UTF-8):

    Статус: В работе

    Заметка:
    Позвонить клиенту.
    Согласовать размеры.

## Задания на широкоформатную печать

Для папки **# work/# print** используется отдельный редактор заданий. Пробел после # необязателен: #work/#print и смешанные варианты распознаются одинаково.

- Слева внутри страницы — список текстовых заданий; справа — отдельные поля названия, ссылки на файлообменник и описания.
- Кнопка «Новое задание» открывает новый документ. Файл появляется после сохранения или перехода с заполненного задания.
- Имя файла: print - ГГГГ-ММ-ДД, дата по московскому времени. Расширение берётся из существующего образца; сейчас это .textClipping. При совпадении имени добавляется (2), (3) и далее. Название задания редактируется внутри файла и не меняет его имя.
- Ссылка записывается первой строкой, затем строка «Название: …» и описание, разделённые пустыми строками. Ссылка и название необязательны. В старом задании с заголовком перед ссылкой оба выделяются в отдельные поля; открытие и сохранение без правок не меняют исходный файл.
- Описание пока заполняется вручную. Над ним оставлена неактивная кнопка «Сканировать папки и заполнить описание» с пометкой «Позже» — напоминание о будущей функции.
- Поддерживаются текстовые вырезания macOS (.textClipping), TXT, TEXT, Markdown, RTF и текстовые файлы без расширения. Редактор работает с обычным текстом; при изменении RTF и вырезаний форматирование упрощается.
- Сохранение кнопкой или ⌘S; при переходе в другую папку или к другому заданию изменения сохраняются автоматически.
- Перед записью проверяется, не изменился ли файл в другой программе. Прежнее содержимое сохраняется рядом с заданием в папке «.print-history», внутри подпапки с именем файла. История доступна в Finder и исключена из списка активных заданий в менеджере.

## Запуск

В Launcher (~/Documents/launcher) выберите **Менеджер заказов → Start Веб-интерфейс**. Остановка: **Stop all in Менеджер заказов**.

В Terminal:

    cd ~/Documents/manager
    python3 server.py

Откройте http://127.0.0.1:8765. Порт можно переопределить аргументом: python3 server.py 8766.

При host = 0.0.0.0 менеджер также доступен в локальной сети по адресу http://<IP-адрес-Mac>:8765, без авторизации. Действие «Открыть на Mac» открывает файл на компьютере, где работает сервер.

Launcher использует launcher.json. При смене порта обновите также port и url в нём. Команда Launcher и start.command используют порт из INI.
