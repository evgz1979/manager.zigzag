# Менеджер заказов «Зигзаг»

Веб-интерфейс к архиву заказов: карточки, задачи, закупки, календарь, Telegram Inbox, счета и сверки. Рабочие метаданные хранятся в локальной SQLite на Mac mini M4, исходные вложения и выпущенные копии документов — в iCloud Drive.

## Рабочий доступ

Открой `start.command` или проект «Менеджер заказов → Открыть на M4» в существующем Launcher. Эти действия открывают [LAN-адрес M4](http://macmini-m4.local:8765); сервисом управляет пользовательский launchd на M4. «Открыть на Mac» выполняется на серверном Mac.

Для поездки открой «Launcher → Менеджер заказов → Start Перенос между M4 и MacBook». Передача переносит рабочую установку на внутренний диск MacBook и возвращает её с правками после поездки. [Порядок переключения](docs/operations.md#выездной-режим).

Отдельный защищённый внешний вход подготовлен для `manager.actu.cc`. Последнее сохранённое состояние DNS-перехода относится к 2 ноября 2026 года; актуальная доступность этой документационной работой не проверялась. [Настройка и ограничения](docs/operations.md#удалённый-доступ).

## Локальная разработка

Локальный `manager.ini` указывает на тестовый `data/dev-documents` и порт 8766:

```sh
mkdir -p data/dev-documents
python3 server.py
```

Открой [локальный тестовый интерфейс](http://127.0.0.1:8766). Рабочий корень iCloud в локальных настройках не используется. Подробности окружения и безопасной проверки — в [разработке](docs/development.md).

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Для JS-сценариев Node должен быть в PATH; нативные проверки требуют macOS SDK. [Проверка документации и полный порядок](docs/development.md#проверка-документации).

Нативное приложение `mobile/` сохранено для будущей адаптации; рабочий обработчик обмена сейчас отключён. Телефонный веб-интерфейс и этот старый протокол — разные части проекта. [Статус mobile](mobile/README.md).
