# Менеджер заказов

Локальный менеджер для папок заказов по годам. Код приложения лежит отдельно в `~/Documents/manager`, а данные читаются из `~/Library/Mobile Documents/com~apple~CloudDocs/Зигзаг/<год>`. Доступные годы определяются автоматически по папкам с четырёхзначными названиями. Ручные статусы хранятся в `manager/data/statuses.json` с привязкой к году.

## Запуск

В приложении Launcher (`~/Documents/launcher`) выберите **Менеджер заказов →
Start Веб-интерфейс**. Launcher запускает сервер и открывает интерфейс в браузере.
Для остановки используйте **Stop all in Менеджер заказов**. Конфигурация хранится
в `manager/launcher.json`; автоматический запуск выключен.

Для ручного запуска в Terminal:

```bash
cd "/Users/evgz/Documents/manager"
python3 server.py
```

Откройте:

```text
http://127.0.0.1:8765
```

Сервер слушает `0.0.0.0:8765`, поэтому с другого устройства в той же локальной сети менеджер открывается по адресу `http://<IP-адрес-Mac>:8765`. Доступ извне локальной сети отдельно не настраивается.

## Что умеет

- список клиентов и проектов;
- переключение между годами;
- поиск по клиенту, объекту, этапам и последним файлам;
- фильтр по статусу;
- сортировка;
- ручные статусы и заметки;
- кнопка открытия папки проекта в Finder.

Корень данных можно переопределить переменной окружения `ZIGZAG_DATA_ROOT`, а адрес прослушивания — переменной `MANAGER_HOST`.
