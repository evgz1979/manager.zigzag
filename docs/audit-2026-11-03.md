# Аудит документации — 3 ноября 2026 года

Версия документации **2.122.0**. Аудит относится к локальному checkout `/Users/evgz/Documents/manager`. На дату аудита [инвентаризация](reference/inventory.json) содержала хеши исходников. После перехода 5 ноября 2026 года на устойчивый индекс версии 2 текущий файл содержит только навигацию по объявлениям; исторические хеши остаются в прежней версии файла в Git. Этот отчёт не является результатом свежей проверки рабочего M4 или внешнего DNS.

## Что было до обновления

Пять основных документов `docs/`, корневой README, mobile README и большой AGENTS содержали подробные решения и эксплуатационные сведения, накопленные по датам. При этом не было отдельного системного описания архитектуры, сквозных цепочек операций, языкового разбора, полного справочника объявлений и проверяемого реестра использования модулей.

В текстах оставались конкретные устаревшие формулировки: карточка `!.txt` якобы могла восстановить весь текущий заказ; заметки описывались только как вложенные в заказ; связи — только как симметричные; поставщики закупок — ещё не связанные с `# work`; высота недель — прежняя фиксированная; отправка Telegram — вообще не меняющая SQLite. Эти описания уточнены по текущему коду и поздним решениям.

AST 18 прежних браузерных JS-файлов совпадает с исходным без комментариев/координат. Для десяти нативных исходников удаление вставленных строк точно восстанавливает прежние байты.

**Полный прогон: 701 тест, 246,123 секунды, OK; пропусков нет.** Node был доступен в PATH, поэтому JavaScript-проверки включены. Прогон выполнен вне песочницы на временных тестовых данных. Первоначальный запуск внутри песочницы дал отказы среды: запрет локального bind и NSFileCoordinator для временных каталогов; его ошибки не воспроизвелись при корректном окружении.

## Границы результата

Изменена документация и комментарии; добавлены инструменты инвентаризации, которые не входят в рабочую обработку HTTP. Пользовательская SQLite, вложения, секреты, DNS и launchd не изменялись. Релиз на M4 этой работой не публиковался. Изменение Swift-комментариев меняет хеш исходника и потребует обычной предварительной сборки при будущем деплое.

Нет подтверждения, что целый собственный Python-модуль можно безопасно удалить. Указаны конкретные отключённые ветки, совместимые старые форматы и отдельные CLI/restore-сценарии. Для окончательного удаления нужны отдельная проверка старых данных и решение о поддержке восстановления.

Нативный обмен iPhone остаётся приостановленным. Успешные локальные проверки не являются установкой на физический телефон или проверкой реальной доставки iCloud между устройствами. Сведения внешней настройки от 2 ноября сохранены как последнее известное состояние, а не переобъявлены актуальной сетевой проверкой.
