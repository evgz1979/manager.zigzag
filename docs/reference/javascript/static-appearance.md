# static/appearance.js

Сгенерировано из текущих объявлений. [Все модули](../README.md).

Исходник: [static/appearance.js](../../../static/appearance.js).

Непосредственные вызовы извлечены из синтаксиса. Динамический dispatch, вызываемые callbacks и побочные эффекты вложенных функций могут находиться в других объявлениях. Комментарии описывают назначение, тело исходника остаётся точным контрактом.

<a id="symbol-apply"></a>

## apply

[static/appearance.js](../../../static/appearance.js) · `FunctionDeclaration`.

```javascript
function apply(mode)
```

Применяет выбранное оформление и синхронизирует переключатель в настройках.

Отсутствующее или неизвестное значение означает автоматическую тему.

Прямые присваивания полям/свойствам: `root.dataset.appearance`, `choice.checked`.
