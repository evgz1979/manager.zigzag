# Документация «Менеджера заказов Зигзаг»

Версия **2.123.0**, обновлено **4 ноября 2026 года**. Это единая точка входа в правила, устройство приложения и исходники. Версия документации не является версией приложения или формата карточки.

## Что сейчас есть

Рабочий сервер и SQLite находятся на Mac mini M4; браузеры обращаются к нему, исходные документы остаются в iCloud. Локальный checkout настроен на изолированные `data/dev-documents`, порт 8766. Сохранённый протокол нативного iPhone-приложения приостановлен. Веб-интерфейс адаптирован к узкому экрану.

Удалённый вход реализован отдельным защищённым слушателем с собственным паролем. Последняя зафиксированная эксплуатационная проверка от 2 ноября: Tunnel подготовлен, публикация HTTPS ожидала завершения DNS-перехода. Это историческое состояние, **не свежая проверка доступности**; текущая работа обновляет кодовую документацию и не меняет DNS/сервис. [Подробности настройки](operations.md#удалённый-доступ).

## Справочники со ссылками на код

[Индекс всех исходников](reference/README.md) ведёт к отдельному документу каждого модуля. Там перечислены собственные именованные классы и функции, сигнатуры, двухстрочные описания, непосредственные вызовы и явные Python return/raise. Номера строк соответствуют этому срезу исходников.

[HTTP API](reference/http-api.md) содержит ветки маршрутизации с привязкой к коду; список читаемых полей не выдаётся за полную обязательную JSON-схему. [SQLite DDL](reference/sqlite-schema.md) получен из исходников без чтения рабочей базы. [Инвентаризация](reference/inventory.json) фиксирует покрытие и хеши файлов.

Покрытие включает собственный рабочий Python, эксплуатационные скрипты, именованные браузерные функции/методы, нативные Swift-типы/методы и C-обёртку. Приостановленные собственные модули также описаны. Тестовые методы и сторонние библиотеки описываются на уровне назначения; анонимные callbacks, вычисляемые свойства и встроенные HTML-скрипты — в контексте владельца.

## Как поддерживать

Меняя поведение, обновляй соответствующее правило, объяснение архитектуры/сценария, применимые инструкции AGENTS и журнал. Меняя функцию, поддерживай две строки перед её объявлением: назначение и существенный контракт. После сдвига кода пересобери справочник и проверь ссылки по [инструкции разработки](development.md#проверка-документации).

Старый накопительный обзор сохранён в [историческом снимке 2.121.2](history/overview-2.121.2.md), прежний README проекта — [отдельно](history/project-readme-20261102.md). Они нужны для истории и не являются параллельными актуальными инструкциями. Идеи без обещания реализации — [PROJECT_NOTES](../PROJECT_NOTES).
