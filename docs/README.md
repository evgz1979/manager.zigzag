# Документация «Менеджера заказов Зигзаг»

Версия **2.137.0**, обновлено **8 ноября 2026 года**. Это единая точка входа в правила, устройство приложения и исходники. Версия документации не является версией приложения или формата карточки.

## Что сейчас есть

Рабочий сервер и SQLite находятся на Mac mini M4; браузеры обращаются к нему, исходные документы остаются в iCloud. Локальный checkout настроен на изолированные `data/dev-documents`, порт 8766. Сохранённый протокол нативного iPhone-приложения приостановлен. Веб-интерфейс адаптирован к узкому экрану.

Удалённый вход **https://manager.actu.cc** работает через Cloudflare Tunnel с собственным паролем. Проверено **4 ноября 2026 года** — HTTPS с действительным сертификатом открывает форму входа, API и файлы закрыты до авторизации, HTTP перенаправляется на HTTPS. DNSSEC включён в Cloudflare, новый DS сохранён в Spaceship и подтверждён публичным резолвером с AD=true. Локальный вход доступен по прежнему адресу. [Подробности настройки](operations.md#удалённый-доступ).

## Справочники со ссылками на код

[Индекс всех исходников](reference/README.md) ведёт к отдельному документу каждого модуля. Там перечислены собственные именованные классы и функции, сигнатуры, двухстрочные описания, непосредственные вызовы и явные Python return/raise. Объявления имеют постоянные якоря по имени; сдвиг строк исходника не меняет ссылки.

[HTTP API](reference/http-api.md) содержит ветки маршрутизации с привязкой к коду; список читаемых полей не выдаётся за полную обязательную JSON-схему. [SQLite DDL](reference/sqlite-schema.md) получен из исходников без чтения рабочей базы. [Инвентаризация](reference/inventory.json) версии 2 хранит пути, имена, типы и якоря объявлений, по одному символу на строку. Координаты и хеши целых исходников в неё не входят; актуальность проверяется повторным построением справочника.

Покрытие включает собственный рабочий Python, эксплуатационные скрипты, именованные браузерные функции/методы, нативные Swift-типы/методы и C-обёртку. Приостановленные собственные модули также описаны. Тестовые методы и сторонние библиотеки описываются на уровне назначения; анонимные callbacks, вычисляемые свойства и встроенные HTML-скрипты — в контексте владельца.

## Как поддерживать

Меняя поведение, обновляй соответствующее правило, объяснение архитектуры/сценария, применимые инструкции AGENTS и журнал. Меняя функцию, поддерживай две строки перед её объявлением: назначение и существенный контракт. Пересобери справочник и проверь постоянные ссылки по [инструкции разработки](development.md#проверка-документации); отдельная перестановка строк не должна менять его содержимое.
